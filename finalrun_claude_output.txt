What changed

Pipeline output: pipeline.py now includes each return's full record in every queue entry. It writes to tempHTML/queue.json by default, and evaluate_queue.py reads from there.
queue.json contents: it holds the real output of the earlier live run, with each record added from returns.json. This made no new agent calls. It replaces the old sample data, which used names like product, category: wearable and resell.
script.js: it uses the shared names and handles returns the rule gate stopped.
Gate-stopped returns: they show the gate's reasons instead of agent figures. They can only go to human review, and the button reads "Confirm human review".
Destination edit: the choices are the gate's allowed destinations plus human review. Changing a destination shows the agent's own figures for that option.
Detail panel: it shows the rule gate result, the options the agent compared, the evidence, the customer notes (marked untrusted), and the date as written (local time).
Filter and keys: the old "Flag" filter became a "Rule Gate" filter (passed, hazard, incomplete). RET-2001 appears twice on purpose, so rows are keyed on test_case_id.
Removed: resell, the invented weight field, and the old hazard flag names.
quarterly_report.json: resell is merged into restock, and each quarter still totals 100%. The waste bucket stays as the pre-agent disposal share.
Docs and tests: docs/CONTRACT.md gained a dashboard section with the field mapping. tempHTML/README.md was empty and now has run steps. New contract tests check that queue.json and the report use the shared vocabulary.
